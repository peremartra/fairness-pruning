# results/e4

Small result table of experiment E4 (capability cost of the interventions). The full outputs (per-item tables, intervals, checks, provenance)
are on Drive, `fair_pruning/results/e4/` (`<unit>/items/` and `analysis/<timestamp>_caps/`); see `analysis/e4/README.md`.

| File | Content |
|---|---|
| `e4_capabilities_table.csv` | One row per unit, task and comparison: `value_a`, `value_b` (accuracy in % or word perplexity), `delta` (pp, or relative % for WikiText), 95 % paired-bootstrap interval (B = 10,000), `unit_of_delta`, `verdict` (margin ±1 pp). Copied from the `e4_capabilities_table.csv` of the Drive analysis folder; the run folder name is given in the commit message. |
